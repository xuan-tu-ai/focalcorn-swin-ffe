# Figures

Figures written by `src/report.py`. Generated by running the pipeline
in [../REPRODUCE.md](../REPRODUCE.md).

`make_prior_works.py` and `make_focal_weight.py` draw the two figures that do not
depend on saved predictions; run them from this folder.

`F2_architecture.tex` is the architecture diagram (TikZ). Its input thumbnail is
cropped from the dataset first, from the repository root:

```bash
python figures/make_architecture_input.py   # writes figures/F2_input.jpg
cd figures && pdflatex F2_architecture.tex  # writes F2_architecture.pdf
```
